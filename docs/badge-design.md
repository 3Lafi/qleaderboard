# أصول وسام المعتمدة

وسام القرآن وأيقونة التطبيق: `images/badges-assets/frames/quran-botanical-v10.webp` وأيقونات `images/app-icons/badge-v10-*`.

حُفظ المرجع الأصلي `images/badges-assets/wisam badge.jpg` والخط الدائري والإطار وشكل الوسام. التعديل النباتي يقتصر على نطاق الزخرفة المحيط بالخط. صفحة المقارنة تعرض النباتية الأصلية v6 والنباتية المحسّنة v10.

مصادر وإعادة توليد:

```sh
node scripts/build-app-icons.mjs
node scripts/build-botanical-badge.mjs
node scripts/build-badge-frames.mjs
```

تحتاج البرامج إلى ImageMagick (`magick`) وlibrsvg (`rsvg-convert`). الأول يولد المرجع المقصوص وأيقوناته، والثاني يطبق الزخرفة النباتية ويولد أيقونات التطبيق المعتمدة. الثالث يولد إطاري الأجزاء والسور v5 ووسام إتمام الخطة v6.

مصدر النباتية المعتمدة: `images/badges-assets/sources/quran-botanical-v10.png`. مصادر الأجزاء والسور ووسام الإتمام محفوظة أيضاً. SVG الخاص بالقرآن يجمع صوراً وقناع قص قابل للتحرير، ولا يدّعي أنه إعادة رسم متجهية كاملة.

أزيلت التجارب الهندسية المرفوضة وإطارات وأيقونات الإصدارات القديمة غير المستخدمة. لم تُحذف مصادر الخط أو المرجع الذي قدمه المستخدم.
